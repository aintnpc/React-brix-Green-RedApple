# 다이어트 앱 — 로직 문서

## 1. 유저 플로우

```
앱 실행
  └── 세션 없음 → 로그인
  └── 세션 있음, 온보딩 미완료 → 온보딩
  └── 세션 있음, 온보딩 완료 → 홈 (탭)
```

---

## 2. 온보딩 (5단계)

| 단계 | 입력 항목 |
|------|----------|
| 1. 기본 정보 | 성별, 키(cm), 현재 체중(kg), 나이 |
| 2. 목표 설정 | 체중 감량 / 유지 / 근육 증가 + 목표 체중(kg) |
| 3. 목표 기간 | 1개월 / 2개월 / 3개월 / 6개월 (감량 목표만) |
| 4. 활동량 | 거의 안 움직임 / 가볍게 / 보통 / 활동적 / 매우 활동적 |
| 5. 플랜 확인 | 계산된 일일 칼로리 + 탄단지 목표 확인 |

> 목표가 "유지" 또는 "근육 증가"인 경우 3단계(목표 기간)는 스킵됨

---

## 3. 핵심 계산 로직

### 3-1. BMR (기초대사량) — Harris-Benedict 공식

```
남성: 88.362 + (13.397 × 체중) + (4.799 × 키) − (5.677 × 나이)
여성: 447.593 + (9.247 × 체중) + (3.098 × 키) − (4.330 × 나이)
```

### 3-2. TDEE (총 일일 에너지 소모량)

```
TDEE = BMR × 활동량 계수

활동량 계수:
  거의 안 움직임  × 1.200
  가볍게 활동    × 1.375
  보통 활동      × 1.550
  활동적         × 1.725
  매우 활동적    × 1.900
```

### 3-3. 목표별 일일 칼로리 목표

```
체중 감량  → TDEE × 0.80  (20% 적자)
체중 유지  → TDEE
근육 증가  → TDEE × 1.10  (10% 흑자)
```

### 3-4. 탄단지 비율

| 목표 | 탄수화물 | 단백질 | 지방 |
|------|---------|--------|------|
| 감량 | 35% | 35% | 30% |
| 유지 | 45% | 25% | 30% |
| 근육 | 45% | 30% | 25% |

> 칼로리 → g 환산: 탄수화물·단백질 ÷ 4, 지방 ÷ 9

## 4. 감량 플랜 계산 (핵심)

### 4-1. 전체 플랜 (`calculateWeightPlan`)

```
1kg 지방 = 7,700 kcal

총 소모 칼로리 = (현재 체중 − 목표 체중) × 7,700
하루 필요 적자 = 총 소모 칼로리 ÷ 목표 기간(일)

식단 적자 한도 = TDEE × 25%  (근손실 방지 안전선)
최소 운동 소모 = 하루 필요 적자 − 식단 적자 한도  (음수면 0)
```

**예시** — 75kg → 70kg, 90일 목표, TDEE 2,200 kcal:
```
총 소모 = 5 × 7,700 = 38,500 kcal
하루 적자 = 38,500 ÷ 90 ≈ 428 kcal
식단 한도 = 2,200 × 25% = 550 kcal
최소 운동 = 428 − 550 = 0 (식단만으로 가능)
```

### 4-2. 오늘 필요 운동량 (`calculateDailyPlan`)

매 식단 기록 시 실시간으로 재계산됨.

```
식단 적자   = TDEE − 오늘 섭취 칼로리
운동 필요량 = 하루 필요 적자 − 식단 적자 − 오늘 운동 소모량
            (음수면 0 → 오늘 목표 달성)
```

**예시** — TDEE 2,200, 하루 적자 목표 428:
```
오늘 섭취: 2,400 kcal → 식단 적자 = −200 (초과 섭취)
운동 필요량 = 428 − (−200) − 0 = 628 kcal
```
→ "오늘 치킨 먹었으니 628 kcal 더 태워야 해요"

### 4-3. 목표 단축/연장 계산

```
오늘 실제 적자 = 식단 적자 + 운동 소모
남은 칼로리    = 총 소모 목표 − 지금까지 누적 적자
예상 남은 날   = 남은 칼로리 ÷ 오늘 실제 적자

목표 앞당김 = 원래 목표일 − 예상 남은 날
  양수 → "N일 앞당겨짐"
  음수 → "N일 지연"
```

## 5. 운동 소모 칼로리 계산 (MET 기반)

```
소모 칼로리 = 체중(kg) × 분당 계수 × 운동 시간(분)
```

| 운동 | 분당 계수 (체중 1kg 기준) |
|------|------------------------|
| 빠르게 걷기 | 0.063 kcal |
| 달리기 (8km/h) | 0.133 kcal |
| 자전거 | 0.100 kcal |
| 계단 오르기 | 0.110 kcal |
| 줄넘기 | 0.120 kcal |

**예시** — 70kg, 달리기 30분:
```
0.133 × 70 × 30 = 279 kcal
```

---

## 6. 추천 운동 생성

운동 필요량이 있을 때, 5가지 운동 각각에 대해 필요 시간 계산:

```
필요 시간(분) = 운동 필요량 ÷ (분당 계수 × 체중)
```

홈화면에서 상위 2개, 운동 탭에서 전체 5개 표시.

| 스토어 | 저장 데이터 | 주요 역할 |
|--------|-----------|----------|
| `useAuthStore` | session, bodyInfo, macroGoals | 로그인 상태, 신체정보, 목표 칼로리 |
| `useDietStore` | MealLog[] | 식단 기록 CRUD |
| `useExerciseLogStore` | ExerciseLog[] | 운동 기록, 날짜별 소모 칼로리 합산 |
